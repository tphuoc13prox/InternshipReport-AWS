# Summary Report: "AWS Cloud and AI Day Hanoi"

### Event Objectives

- Explore the latest developments in AWS Cloud and Artificial Intelligence.
- Learn from AWS experts, engineers, solution architects, customers, and technology partners.
- Understand practical applications of AI, data analytics, cloud migration, and modern application development.
- Discover how agentic AI can be applied to solve real-world problems.
- Connect with other developers, cloud learners, and technology professionals.

### Keynote Speakers

- **H.E. Pham Duc Long – Deputy Minister of Science & Technology**
- **H.E. Jennifer Wicks – U.S. Ambassador to Vietnam**
- **Dr. Werner Vogels – CTO, Amazon.com**
- **Eric Yeo – Country General Manager Malaysia, Vietnam, Indochina, AWS**
- **Mai Le – Director of Product Management, Katalon**
- **Dr. Jens Lottner – Chief Executive Officer, Techcombank**

### Event Information

- **Event:** AWS Cloud and AI Day Hanoi
- **Date:** September 29, 2026
- **Venue:** JW Marriott Hotel Hanoi
- **Duration:** One-day in-person event
- **Organizer:** Amazon Web Services (AWS)
- **Registration:** Complimentary

### Key Highlights

- **Keynote Session:** Exploring how AWS technologies and agentic systems can help developers turn ideas into practical solutions.
- **Technical Sessions:** Sessions covering AI, data and analytics, cloud migration, and modern application development.
- **Agentic AI:** Exploring the development and deployment of AI agents for practical applications.
- **Hands-on Workshops:** Opportunities to gain practical experience with AWS Cloud technologies.
- **Expo:** Technical demonstrations and interactive showcases from AWS and its partners.
- **Developer Community Zone:** Opportunities to connect with other developers and members of the AWS community.
- **Startup Zone:** Demonstrations and solutions from AWS startup customers working on areas such as FinTech, AI, and Commerce.
- **8-Bit Agents Activation:** An interactive activity focused on building and deploying AI agents.

### Key Takeaways

- **Cloud and AI Integration:** Modern applications increasingly combine cloud infrastructure with AI capabilities to solve practical business problems.
- **Agentic AI:** AI agents can go beyond generating responses by interacting with tools and performing tasks autonomously.
- **AWS Architecture:** Different AWS services can be combined to build scalable AI and cloud applications.
- **Data Foundation:** Reliable data infrastructure is an important foundation for building AI-ready applications.
- **Real-World Applications:** Customer stories and technical sessions demonstrated how cloud and AI technologies can be applied in different industries.

### Applying to Work

The knowledge gained from the event can be applied to future AWS and AI projects by:

- Using AWS services to build scalable AI applications.
- Applying cloud architecture principles when designing AI systems.
- Exploring agentic AI and AI agents for practical automation.
- Using appropriate data and analytics services as part of an AI pipeline.
- Considering AWS deployment, scalability, and infrastructure requirements when developing AI projects.

### Event Experience

Participating in AWS Cloud and AI Day Hanoi provided valuable exposure to current developments in cloud computing and artificial intelligence. The event connected technical knowledge with real-world applications through keynote presentations, technical sessions, demonstrations, workshops, and discussions with AWS experts and technology partners. The sessions on AI and agentic systems were particularly relevant to my background as an AI student and helped me better understand how AI solutions can be developed and deployed using cloud infrastructure.
